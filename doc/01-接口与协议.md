| 用途 | 地址 |
|---|---|
| 学校服务端（北京语言大学） | `https://tyjx.blcu.edu.cn/appapi/` |
| 中央学校列表 | `https://sknow.com.cn/appapi/getschoollist.php` |

## 二、登录协议

```
POST https://tyjx.blcu.edu.cn/appapi/login.php
Content-Type: application/x-www-form-urlencoded
```

### 请求参数

| 字段 | 示例 | 说明 |
|---|---|---|
| `schoolno` | `10032` | 学校编号（固定 BLCU） |
| `studentno` | `202311581199` | 学号 |
| `pwd` | `6fc6c36e...` | **密码的 MD5 小写十六进制（无盐）** |
| `subtype` | `student` | 用户类型 |
| `machineno` | 32 位十六进制 | 机器编号（随机生成并持久化） |
| `phonebrand` | `HUAWEI` | 设备品牌 |
| `phonemodel` | `DCO-AL00` | 设备型号 |
| `sysrelease` | `12` | 系统版本 |
| `systype` | `android` | 系统类型 |
| `appversion` | `1.2.22` | 上报版本号 |

### 响应

```json
{
  "code": 0,
  "msg": "登录成功",
  "data": {
    "studentname": "…",
    "studentsex": "男",
    "userid": "76149276",
    "studentno": "202311581199",
    "subtype": "student",
    "login_token": "base64(...).<64位hex签名>",
    "login_token_expire": 1807613598,
    "upload_token": "base64(...).<64位hex签名>",
    "upload_token_expire": 1792147998,
    "upload_proto": "2"
  }
}
```

> `code == 0` 为成功。`upload_token` 是上传签名所需的密钥，由服务器签发、会过期。

## 三、跑步规则接口

```
POST https://tyjx.blcu.edu.cn/appapi/getRunParam.php
参数：schoolno、studentno
```

返回当前有效的跑步规则（取 `data[0]`）：

| 字段 | 示例 | 说明 |
|---|---|---|
| `ruleid` | `5` | 规则编号 |
| `eventno` | `802` | 事件编号 |
| `eventname` | `校内定向跑` | 事件名 |
| `malespeed` / `femalespeed` | `1.67-8.34` | 速度范围（m/s，= 10~2 min/km） |
| `maleminlimit` / `femaleminlimit` | `2000` | 单次最低里程（米） |
| `maletotallimit` / `femaletotallimit` | `4000` | 累计里程上限（米） |

> `getRunArea.php` 返回打卡区域，BLCU 当前返回空 `data: []`（无固定打卡点）。

## 四、上传协议

```
POST https://tyjx.blcu.edu.cn/appapi/uploadRunData.php
Content-Type: application/x-www-form-urlencoded
```

### 24 个表单字段

| 字段 | 说明 |
|---|---|
| `begintime` / `endtime` | 跑步起止时间（Unix 秒） |
| `uid` / `studentno` / `schoolno` | 用户、学号、学校 |
| `distance` / `usetime` / `speed` | 里程（米）、用时（秒）、均速（km/h） |
| `eventno` / `ruleid` / `path` / `pointstatus` | 规则相关（eventno/ruleid 来自 getRunParam；path/pointstatus 为固定值） |
| `atttype` | 出勤类型（空字符串） |
| `location` | GPS 轨迹（见 [03-数据格式.md](03-数据格式.md)） |
| `datalog` | 跑步日志（gzip + base64url） |
| `datalog_enc` | `gzip_base64url` |
| `platform` / `appversion` / `device_model` | `android` / `1.2.22` / `品牌 型号` |
| `upload_token` | 登录返回的上传令牌 |
| `timestamp` | 请求时间戳 |
| `sign` | 请求签名（见 [02-签名算法.md](02-签名算法.md)） |
| `payload_debug_canonical` | 签名原文（调试字段） |
| `payload_sign` | 载荷签名 |

### 响应

```json
{ "code": 0, "msg": "成功" }
```

> `code == 0` 为上传成功。
