## 二、抓包

Flutter（Dart `HttpClient`）默认**不读 Android 系统代理**，Charles 抓不到。解法：iptables 透明代理强制拐流量。

```bash
adb root
# 强制 http（80）流量 DNAT 到宿主机 Charles
adb shell iptables -t nat -A OUTPUT -p tcp --dport 80 \
  -j DNAT --to-destination <宿主机IP>:8888
```

Charles 开启 `Proxy → Proxy Settings → Enable transparent HTTP proxying`。

> 上传接口走 http 明文，无需安装证书即可抓到明文。

## 三、Flutter AOT 反编译

新版 App 为 Flutter AOT，代码编译进 `libapp.so`。使用 **blutter** 反编译：

1. 提取 `lib/arm64-v8a/libapp.so` 与 `libflutter.so`。
2. 环境：Linux（WSL Ubuntu 24.04 + g++ 13）+ `libcapstone-dev`、`libicu-dev`、`pyelftools`。
3. 运行：
   ```bash
   python3 blutter.py path/to/lib/arm64-v8a out_dir
   ```
   blutter 自动识别 Dart 3.11.4，下载 Dart SDK 源码并编译后输出：
   - `pp.txt` —— 对象池（字符串、类、函数）
   - `objs.txt` —— 对象表
   - `asm/` —— 全部函数反汇编

### 关键定位

| 目标 | 位置 |
|---|---|
| 登录逻辑 | `asm/campus_running_app/data/providers/auth_provider.dart` → `login()` |
| 密码哈希 | `AuthProvider::md5Hash`（MD5，无盐） |
| 上传逻辑 | `asm/campus_running_app/data/repositories/run_repository_impl.dart` → `uploadRunningRecord()` |
| 签名计算 | `RunRepositoryImpl::_buildUploadSign()`（HMAC-SHA256，key=upload_token） |

## 四、签名破解过程

1. 抓包拿到一次真实上传，字段 `payload_debug_canonical` 直接泄露签名原文。
2. 实测验证 `location_hash = SHA256(location)`、`datalog_hash = SHA256(datalog)` 完全一致。
3. 穷举验证 `payload_sign = HMAC-SHA256(canonical, upload_token)` 命中。
4. `sign` 字段无法通过静态字符串挖掘命中，最终通过 blutter 反汇编 `_buildUploadSign` 还原：
   ```
   key  = upload_token
   msg  = upload_token + begintime + endtime + timestamp
   sign = HMAC-SHA256(msg, key)
   ```

## 五、验证

用 Python 脚本重放完整登录 + 上传流程，服务器返回 `{"code":0,"msg":"成功"}`，协议与签名算法全部验证通过。
