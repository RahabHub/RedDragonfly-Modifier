# 02 · 签名算法

上传请求需要计算**两个 SHA256 哈希**与**两个 HMAC-SHA256 签名**，密钥均为 `upload_token`。

## 一、两个 SHA256 哈希

```
location_hash = SHA256(location)    # 对 location 轨迹字符串求哈希
datalog_hash  = SHA256(datalog)     # 对 datalog 字符串（base64url 之后）求哈希
```

> 因为 location / datalog 体积大，不直接参与签名，只参与哈希。

## 二、canonical 字符串（签名原文）

字段顺序固定，行分隔符 `\n`，结尾无换行：

```
v=1
uid=76149276
schoolno=10032
studentno=202311581199
begintime=1792054177
endtime=1792054707
distance=2022
speed=13.735915190157154
usetime=530
eventno=802
ruleid=5
path=1,12,2,10
pointstatus=3
platform=android
appversion=1.2.22
location_hash=9f83acbfc5475d6a3847c0ff93774b1d90c2798340c2fb9bb60ba5c234cab99c
datalog_enc=gzip_base64url
datalog_hash=9a8e7cd536f7c5adfa2d5fd00507ca98734ad09c2ed5cb2fe6a6484c3012c3e3
timestamp=1792054877
```

## 三、payload_sign

```python
payload_sign = HMAC-SHA256(message=canonical_string, key=upload_token)
```

## 四、sign

```python
sign = HMAC-SHA256(
    message = upload_token + begintime + endtime + timestamp,  # 纯拼接，无分隔符
    key     = upload_token,
)
```

## 五、签名汇总

| 字段 | 算法 | 消息 | key |
|---|---|---|---|
| `location_hash` | SHA256 | `location` | — |
| `datalog_hash` | SHA256 | `datalog` | — |
| `payload_sign` | HMAC-SHA256 | canonical | `upload_token` |
| `sign` | HMAC-SHA256 | `upload_token + begintime + endtime + timestamp` | `upload_token` |

## 六、验证

上述算法均通过抓包数据重算比对验证（重算值与真实请求字段完全一致）。

## 七、upload_token 结构

```
upload_token = base64(uid|studentno|schoolno|expire|type) + "." + <64位hex签名>
```

示例解码（base64 部分）：

```
76149276|202311581199|10032|1792147998|2
```

后缀的 64 位 hex 是服务器用私密 key 对 base64 部分做的 HMAC-SHA256，**客户端无法伪造**，只能从登录响应 / `getUploadToken.php` 获取。
